MultiPCAPSearch 1.0.0 is the first release with prebuilt binaries for Windows, macOS and Linux. You no longer need to install Qt and build it yourself.

**You still need [Wireshark](https://www.wireshark.org/download.html) installed.** MultiPCAPSearch runs its `tshark` tool and finds it automatically (or use *Settings > Locate tshark...*).

### Downloads
- **Windows 10/11 x64:** `MultiPCAPSearch-windows-x64.zip`. Unzip it and run `MultiPCAPSearch.exe`.
- **macOS 12+ (Apple Silicon and Intel):** `MultiPCAPSearch-macos-universal.dmg`. The app is unsigned, so right-click it and choose *Open* the first time.
- **Linux x86_64:** `MultiPCAPSearch-linux-x86_64.AppImage`. `chmod +x` it and run it.

### Fixed
- Crash when adding a PCAP while filtering is happening (#2)
- The file browser now remembers the last folder you opened (#1)
- The window contents now scale when the window is resized

### New
- Cross-platform (Qt 6 + CMake); uses your installed tshark directly instead of a bundled copy run through PowerShell
- Add several captures at once, drag and drop captures onto the window, or pass them on the command line
- Stop button to cancel running searches; configurable number of parallel searches
- Export results to CSV
- An empty filter counts all packets
- Filters and window layout are remembered between sessions
- Errors (red) and tshark warnings (amber) shown per cell, with details in the tooltip
- Cached results are refreshed automatically when a capture file changes on disk

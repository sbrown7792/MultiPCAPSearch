MultiPCAPSearch 1.0.1 is a licensing release. There are no functional changes since [1.0.0](https://github.com/sbrown7792/MultiPCAPSearch/releases/tag/v1.0.0).

MultiPCAPSearch is now free software, licensed under the **GNU Affero General Public License v3.0 or later**. The Windows zip includes the `LICENSE` file, and the About box states the license. The release binaries bundle Qt, used under the GNU LGPL v3. `tshark` is not included and runs as a separate program.

**You still need [Wireshark](https://www.wireshark.org/download.html) installed.** MultiPCAPSearch finds its `tshark` automatically (or use *Settings > Locate tshark...*).

### Downloads
- **Windows 10/11 x64:** `MultiPCAPSearch-windows-x64.zip`. Unzip it and run `MultiPCAPSearch.exe`.
- **macOS 12+ (Apple Silicon and Intel):** `MultiPCAPSearch-macos-universal.dmg`. The app is unsigned, so right-click it and choose *Open* the first time.
- **Linux x86_64:** `MultiPCAPSearch-linux-x86_64.AppImage`. `chmod +x` it and run it.
